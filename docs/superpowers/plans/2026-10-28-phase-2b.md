**Spec:** User request dated 2026-10-28, Fase 2B.

## Global Constraints

- Preserve `job_roles` and migration 012; only add migration 013.
- Company identity always derives from authenticated database identity, never client input.
- Profiles and analysis snapshots are immutable once used; an edit creates a new version.
- General weights must total 100; requirement weight is positive; levels are 0–5.
- No training, ranking, gamification, or employment decisions.

## Formula

- Behavioral score: mean of `max(0, 100 - abs(actual - expected))` across the four dimensions, rounded to one decimal.
- Competency score: for each expected level `0`, score 100; otherwise `min(100, actual / expected * 100)`, weighted by requirement weight; rounded to one decimal.
- Overall score: weighted behavioral + competency score, divided by 100, rounded to one decimal. It is unavailable unless both sources exist.
- Classification: 90+ muito alta; 75+ alta; 60+ moderada; 40+ baixa; otherwise muito baixa.
- Gap criticality uses `expected - actual` times requirement weight: 10+ crítica, 6+ alta, 3+ média, otherwise baixa.

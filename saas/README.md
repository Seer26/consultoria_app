# Consultoria SaaS

Nova base web para o sistema de consultoria empresarial, criada em paralelo ao app Flutter existente.

## Estrutura

```text
saas/
  apps/
    api/        # Backend Node.js + SQLite
    web/        # Frontend React
  packages/
    domain/     # Tipos, pilares e regras compartilhadas
```

## Escopo desta primeira entrega

- Estrutura inicial pronta para crescimento
- Módulo de diagnóstico como primeiro fluxo funcional
- Pontuação por pilar
- Identificação simples de pontos fortes e fracos
- Geração inicial de ações automáticas
